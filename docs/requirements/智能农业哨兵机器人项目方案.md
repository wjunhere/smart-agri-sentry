# 智能农业哨兵机器人项目方案

> ⚠️ **历史方案**：环境传感器已迁移至固定 LoRa 节点，移动节点仅负责视觉检测（见 [`docs/HARDWARE.md`](../HARDWARE.md) §2.2）。

> **历史文档**：本文为项目初始方案。当前实现已调整：GPS 模块已移除，导航采用 mapless Nav2（目标 LiDAR SLAM），模型使用 ONNX 源格式 + RDK X5 `.bin` 运行时。最新状态请见 [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md)。

## 项目概述

### 项目名称：**智农哨兵**

### 项目背景

针对传统农业监测设备"布线难、联网难、适应性差"的痛点，本项目设计一款面向复杂农田环境的自主移动农业监测机器人。

### 项目目标

开发一套低成本、高机动性的智能化解决方案，实现对农作物病害、生长环境及土壤肥力的实时原位监测。

## 核心亮点

### 全地形适应能力

● 履带式底盘设计，适应非结构化地形

● 解决轮式机器人易打滑、陷车问题

### 多模态数据融合

● **视觉诊断**：计算机视觉（叶片图像）分析

● **环境感知**：土壤墒情、空气湿度等多维度数据

● **融合算法**：加权决策算法大幅降低单一视觉识别的误报率

### 端侧离线智能

● 深度学习模型量化部署

● 无需4G/5G网络即可实时推理

● 保护数据隐私，保证信号盲区作业稳定性

### 人机共融控制

● "自主巡检+远程接管"双模控制策略

● 正常状态自主沿田垄巡逻（可选）

● 异常状态通过本地WiFi热点切换至人工操控

## 系统架构

### 硬件层

#### 主控单元

● **核心处理器**：RDK X5

● **运动控制器**：STM32F407ZGT6（最小系统板）

● **功能**：AI推理，核心逻辑处理和运动控制

#### 感知系统

**视觉传感器**

● mipi摄像头

● 采集作物图像用于病害识别

**环境传感器**

● 土壤电导率传感器：监测土壤肥力水平

● 土壤pH值传感器：检测土壤酸碱度

● 土壤温度湿度传感器：监测土壤微环境

● 空气温湿度，CO~2~ 传感器：监测微气候环境

● 光合有效辐射传感器：测量植物光合作用光照（可选）

**定位系统**

● RTK-GPS模块：厘米级定位与导航

#### 执行机构

● 双电机驱动履带底盘

● 舵机云台：调整摄像头角度

● 三维舵机驱动的机械臂：实施土壤采样

#### 通信模块

● 板载WiFi模块（AP模式）

● 构建本地局域网

### 算法层

#### 视觉算法

● **模型架构**：轻量化CNN模型（MobileNetV2-Quantized）

● **功能**：病害分类与叶片分割识别

● **优化技术**：模型剪枝与INT8量化

#### 融合算法

代码

```
# 多传感器数据融合逻辑示例
def fusion_diagnosis(vision_data, env_data):
    # 病害概率 = 视觉权重 * 图像特征 + 环境权重 * 叶面湿度
    disease_risk = (0.6 * vision_data.disease_probability + 
                   0.4 * env_data.leaf_humidity_factor)
    return disease_risk
```

#### 控制算法

● PID速度闭环控制算法

● 基于GPS坐标的路径跟踪算法

● 自适应地形调节策略

### 交互层

#### 本地终端

● 手机/平板连接小车热点

● 通过Web网页或APP查看实时数据

● 支持视频流、传感器数据及AI诊断结果展示

#### 可视化界面（可选）

● 车载OLED屏幕显示当前状态

● 电量、模式、关键报警信息实时呈现

## 技术实现

### 硬件选型

#### 主控板

● **型号**：RDK X5

● **特性**：**8核 ARM Cortex-A55** 处理器， **8GB** LPDDR4

● **优势**：搭载的**旭日R5**芯片提供 **10 TOPS** 的高算力，功耗仅3W

#### 摄像头模块

● **型号**：mipi-csi

● **分辨率**：3264*2464

● **视场角**：70°

● **接口**：csi软排线

#### 传感器配置

| 传感器类型 | 接口类型 | 测量范围           | 分辨率    |
| ---------- | -------- | ------------------ | --------- |
| 土壤电导率 | UART     | 0-20dS/m           | 1us/m     |
| 土壤pH值   | UART     | 3-9pH              | 0.1pH     |
| 空气CO~2~  | UART     | 400ppm-5000ppm     | 1ppm      |
| 空气温湿度 | UART     | -40-125℃, 0-100%RH | 0.1℃,0.1% |
| 土壤温湿度 | UART     | -40-80℃，0-100%RH  | 0.1℃,0.1% |

计划使用两个传感器：

- 七合一空气质量高精度传感器，可以检测CO2，甲醛，TVOC，温湿度PM2.5，PM10，方案目前仅需要温湿度和CO2两种数据，传感器采用uart接口，共有四个接口。

| 接口 | 名称 | 功能           |
| ---- | ---- | -------------- |
| 1    | 5V   | 接电源 5v      |
| 2    | GND  | 电源地         |
| 3    | N/A  | 悬空           |
| 4    | TXD  | uart数据输出脚 |




- 七合一土壤传感器，可以检测土壤的电导率，氮磷钾，温湿度，PH，传感器采用uart接口，共有四个接口。

#### 驱动系统

● **电机**：24V直流减速电机

● **驱动器**：TB6612FNG双路电机驱动

● **编码器**：1000线光电编码器

### 软件架构

#### 操作系统

● **实时操作系统**：FreeRTOS

**任务划分**：

○ 传感器采集任务（100ms周期）

○ AI推理任务（500ms周期）

○ 控制算法任务（20ms周期）

○ 通信处理任务（100ms周期）

#### AI框架

● **训练框架**：TensorFlow Lite for Microcontrollers

● **部署方式**：可通过rdk官方平台robogo快速部署模型

### 电源管理

● **主电源**：24V锂电池组

● **稳压模块**：DC-DC降压至5V/3.3V

● **保护机制**：过流保护、低电量报警

● **续航时间**：4-8小时（典型工况）

## 创新点总结

### 技术创新

1. **多模态融合诊断算法**：首次将视觉识别与多维环境数据融合应用于农业病害诊断

2. **端侧AI轻量化部署**：在资源受限的MCU上实现复杂AI模型的实时推理

3. **全地形自适应底盘**：针对农田特殊地形优化的履带式移动平台

### 应用创新

1. **无网环境解决方案**：完全摆脱对公网的依赖，适应偏远农田环境

2. **移动式监测模式**：相比固定监测站，覆盖范围提升10倍以上

3. **精准农业决策支持**：从"发现问题"到"提供解决方案"的完整闭环

## 风险评估与应对

### 技术风险

1. **算力不足**：采用模型量化与剪枝技术，确保实时性

2. **通信中断**：设计本地缓存机制，网络恢复后自动同步

3. **电源不稳定**：增加稳压电路与低电量保护

### 环境风险

1. **恶劣天气**：设计防水防尘结构，确保全天候作业

2. **复杂地形**：优化底盘设计，增加越障能力

3. **电磁干扰**：采用屏蔽措施，确保通信稳定性
